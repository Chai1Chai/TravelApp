# TravelApp (SmartTrip)

Практическая работа 2. Реализация пользовательского интерфейса мобильного
приложения для планирования путешествий. 16 экранов, статические данные.

## Требования
- Windows 10/11
- JDK 17 (входит в Android Studio)
- Android SDK (устанавливается вместе с Android Studio)
- Интернет при первой сборке (Gradle скачивает зависимости)

## Сборка apk из командной строки
1. Откройте терминал в корне проекта (папка, где лежит файл `gradlew.bat`).
2. Выполните:

       gradlew.bat assembleDebug

   (Linux/macOS: `./gradlew assembleDebug`)
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`

## Установка на устройство
- Эмулятор: перетащите apk в окно эмулятора.
- Телефон: включите отладку по USB и выполните
  `adb install app/build/outputs/apk/debug/app-debug.apk`

## Готовый apk
Скачать: https://github.com/Chai1Chai/TravelApp/releases/latest

## Экраны
Вход, регистрация, главная, города, Пхукет, отели, рестораны, пляжи,
развлечения, избранное, личный кабинет, планирование (3 шага),
маршрут готов, карта маршрута.
